# CodeAlpha_PollingSystem
Decentralized Voting (Polling System) Smart Contract using Solidity for CodeAlpha Blockchain Development Internship.
This project is developed as part of the CodeAlpha Blockchain Development Internship.

## Project Description

The Polling System is a simple decentralized voting smart contract built using Solidity. It allows users to vote for candidates and stores the vote count securely on the blockchain.

## Features

* Add predefined candidates
* Vote for a candidate
* Store vote counts on the blockchain
* View candidate details and results

## Technologies Used

* Solidity
* Remix IDE
* Ethereum Virtual Machine (Remix VM)

## Smart Contract Functions

### vote(uint candidateIndex)

Allows a user to vote for a candidate.

### candidates(uint index)

Returns the candidate name and vote count.
